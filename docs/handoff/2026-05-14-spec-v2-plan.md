## 1. v2 spec 개요

### 1.1 문서명 권고

- **권고**: `spec-common-v2.md` + `spec-time-coordination-v2.md` + `spec-place-recommendation-v2.md` (v1.0 3-파일 구조 유지 — PR-V) — 또는 단일 `spec-coordination-v2.md` 통합 brainstorm 파일 후 v2.0 안정 시점에 3분할 머지
- 대안: `spec-coordination-v2.md` (확장 — 회원/사회/추천 등 코디네이션 전반 포괄)
- **분리 vs 통합**: 분리 권고. 사유:
  - v1.0 (1523줄)이 시연 SoT로 기능 안정 단계 → 수정 최소화로 회귀 위험 통제
  - v2는 신규 의사결정·미결 Q 항목 우선 → 별도 파일에서 자유롭게 brainstorm
  - 추후 v2.0 안정 시점에 v1.0과 머지(또는 v1.0을 archive로 이동) 결정

### 1.2 v1.0 → v2.0 진화 흐름

| 단계 | v1.0 (현재) | v2.0 (목표) |
|---|---|---|
| 의도 분류 | quick_classify (place 분기만) | 4종 (schedule/place/both/general) 전 분기 일관 |
| 거부 누적 | 정규식 + Gemini (auto-trigger만 정상) | 정규식 단축 사각지대 fix, 캘린더 unavailability 동기화 |
| 확정 후 흐름 | maedeup_card 발행 후 종료 | confirm 후속 ("취소/변경") 의도 처리 분기 |
| PII 갭 | 8건 명시 (§8.9) | 8건 중 P0 4건 (계정 삭제·revoke·k-anonymity·archive) |
| Out of scope | 4건 (§11) | 일부 활성화 (recurring·다국어 우선) |
| 추천 plumbing | P0 6건 (시연 차단 해결) | P1 5건 + P2 4건 |

### 1.3 시점 권고

- **v2 작성 시작 트리거**: v1.0 시연 통과 → retrospective 회의 → 결정
- **v1.0 시연 통과 의존**: 강함. v2는 v1.0 시연 결과(magical moment 평가·사용자 피드백)에 따라 우선순위가 재조정될 수 있음.
- **사전 작업 가능**: 본 계획서·신규 Q-시리즈 후보 정리는 v1.0 시연 전에도 가능 (현재 작업)
