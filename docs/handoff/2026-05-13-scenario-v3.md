### I. Backend volume mount는 코드 자동 반영, env_file은 recreate 필요 (참고)
**상황**: `.env`에 `DEMO_FALLBACK_ENABLED=true` 추가 후 `docker restart maedeup-api` → 환경변수 안 보임 (`docker exec maedeup-api env | grep DEMO` 빈 출력).

**원인**: `docker restart`는 컨테이너 프로세스만 재시작, `env_file` 재로드 안 함. Python 코드는 volume mount라 변경 자동 반영, 단 import 캐시는 process 재시작에 의존.

**해결**: `docker compose up -d --force-recreate fastapi-app` — 컨테이너 재생성 + env_file 재로드.
