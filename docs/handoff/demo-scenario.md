# 매듭 졸업 시연 시나리오 v3 — "오랜만의 동아리 회식, 매듭이 다 해줌"

> 시연 SoT 문서. 노션 9주차(2026-05-06) 토글 "통합 시연 시나리오"에서 가져옴.
> 시나리오 변경 시 본 파일 직접 수정 → 다른 문서는 본 파일 참조.

## 컨셉
평범한 회식 잡기 한 번에 매듭의 핵심 기능이 모두 자연스럽게 노출.

- **예상 시간**: 약 3분 30초
- **룸 수**: 1개 (집중도 ↑)

## 참여자

| 멤버 | 역할 | Personal Data 시드 (사전 ✨) |
| --- | --- | --- |
| 지민 | 방장 ✅ | 한식·강남·저녁형 ✨ |
| 수현 | 멤버 ✅ | 채식·홍대 비선호 ✨ |
| 민수 | 멤버 ✅ | 지하철 ✨ |
| 예린 | **게스트** (앱 없음, 카톡 링크) | — |

## 흐름 한눈에

```
ACT 0  메인 투어              30s   [PersonalData ✨ + 위젯 노출]
ACT 1  모임 생성 + 초대 + 게스트 30s   [플로팅바 + InviteModal + 카톡 링크]
ACT 2  채팅 교착 → 다음주 확장 45s   [stalemate + 자연어 거부 + P + N]
ACT 3  TimeBar 시간 합의      25s   [all_members_selected + I]
ACT 4  Partial 카드 발행      10s   [선호 장소 비어있음 → I]
ACT 5  AI 패널 단축 + 확정    30s   [direct_request + Personal Data 활용 + E + J]
ACT 6  학습 + 클로징          30s   [extractor + ✨ 추가 + 메인 누적]
```

| 행동 | 시스템/멘트 |
| --- | --- |
| 메인화면 노출 | `ExplorePage` 9개 위젯 |
| `PersonalData` ✨ 가리키며 | *"이 ✨가 매듭이 이전 모임 대화에서 자동 학습한 데이터예요. 한식·강남·저녁형 — 다 채팅에서 추출됐습니다."* |
| `MeetingList` / `MiniCalendar` | *"이전 모임이 누적되고 캘린더에도 표시됩니다."* |
| 플로팅 바 | *"새 모임은 여기서 시작합니다."* |

## ACT 1. 모임 생성 + 친구 초대 + 게스트 (30초)

| 누가 | 행동 | 시스템 |
| --- | --- | --- |
| 지민 | 메인 → 플로팅 바 **"모임 생성"** 클릭 | 모임 생성 페이지 |
| 지민 | 모임명 `동아리 종강 회식` / 카테고리 식사 / 친구 체크 (수현·민수) → "모임 생성" | 채팅방 진입 |
| 지민 | 선호도 팝업 → 가능 시간 `평일 저녁`, **선호 장소 비워둠** | "일정 조율 시작" |
| 지민 | 채팅방 상단 **"초대" 버튼** → `InviteModal` → **카톡 게스트 링크 복사** (예린용) | 게스트 링크 발급 |
| 수현·민수 | (모바일) `NotificationPanel` 알림 → 클릭 → 입장 + 선호도 (장소 비워둠) | 멤버 갱신 |
| 예린 | (모바일) 카톡 링크 → 닉네임 `예린` → 게스트 입장 | JWT 발급, 게스트 표시 |

> **시연 멘트**: *"모임 만들고 친구 초대. 수현·민수는 알림으로, 예린이는 앱 없어서 카톡 링크로 게스트 참여."*

---

## ACT 2. 채팅 교착 → 자연어 거부 → 다음주 자동 확장 (45초)

| 누가 | 채팅 | 시스템 |
| --- | --- | --- |
| 지민 | "다들 시험 끝나고 한번 보자!" | (1/4) |
| 수현 | "5월 8일 금요일은 동아리 MT라 안 돼" | (2/4) |
| 민수 | "9일은 본가 내려가야 해서 패스" | (3/4) |
| 예린 | "10일 토요일은 좀 쉬고 싶다… 다음주 어때?" | **교착 감지** |
| 시스템 | — | "대화가 길어지네요, AI가 정리해볼게요 🗓️" *(B)* |
| 시스템 | rejected 5/8·5/9·5/10 → 후보 소진 → **다음주 자동 확장** *(N)* | **추천 카드**: "5/12 (월) 18:00 — 전원 가능"<br>**캘린더**: 5/8·5/9·5/10 빨간 카운트 동기화 *(P)* |

> **시연 멘트**:
> 1. *"4번째 메시지에서 자동 개입. 카톡이라면 흐지부지 됐을 거예요."*
> 2. *"'동아리 MT', '본가', '쉬고 싶다' — 거부 발언을 정확히 이해해서 후보에서 제외 + 캘린더에도 빨간 카운트로 동기화."*
> 3. *"이번 주가 다 안 되니까 매듭이 알아서 다음주로 후보를 확장합니다."*

## ACT 4. 일정 확정 (분기)

| 누가 | 행동 | 시스템 |
| --- | --- | --- |
| 4a 빠른 경로 | vote_card에서 **"일정 확정하기"** 한 번 클릭 | **maedeup_card** 발행 |
| 4b 시간 합의 경로 | vote_card에서 **"시간대 변경"** 클릭 | 캘린더 패널 자동 이동 → TimeBar 활성화 → ACT 3 진입 → all_members_selected → maedeup_card 자동 갱신 |

> **4a 시연 멘트**: *"선호 장소를 안 정했어도 일단 시간만 카드로 발행. 장소는 두 가지 방법으로 채울 수 있는데, 오늘은 AI 추천 받아볼게요."*
>
> **4b 시연 멘트**: *"AI가 시간까지 추천해주지만, 더 정밀하게 맞추고 싶으면 When2Meet 방식으로 시간대 합의도 가능합니다."* → 4b로 가서 TimeBar 시연 → ACT 5 장소.

## ACT 5. AI 패널 단축 → Personal Data 활용 → 확정 (30초)

| 누가 | 행동 | 시스템 |
| --- | --- | --- |
| 지민 | (AI 패널) "강남에서 다 같이 갈만한 한식집" | quick_classify → place → **단축 경로** *(E)* |
| 지민 | (채팅에 추가 발화) "나 비린 거 별로야. 회집은 빼자" | personal data 학습 후보 누적 |
| 시스템 | (3~5s) | **장소 카드** + reasoning: *"수현님 채식·홍대 비선호 ✨ 반영. 강남 한식 중 채식 옵션 있는 곳 위주."* |
| 지민 | 장소 클릭 → 캘린더 패널 PlaceDetailPane → "이 장소로 확정" | maedeup_card 갱신 *(J)* — 같은 카드가 partial → 완성으로 진화 |

> **시연 멘트**:
> 1. *"의도가 명확하니까 단축 경로 — 평소 6~15초 → 3~5초."*
> 2. **(임팩트 ↑↑)** *"reasoning 보세요 — '수현님 채식'. 수현이 한 마디도 안 했는데, 이전 모임에서 학습된 데이터로 자동 반영됐어요."*
> 3. *"같은 카드가 partial → 완성으로 진화하는 거 보이시죠. 새 카드 쌓이는 게 아니라 모임의 라이프사이클입니다."*

## 매듭이 해결하는 5가지 — 어디서 보여주나

| 문제 | 시연 위치 |
| --- | --- |
| 의견 안 모일 때 자동 개입 + 자연어 거부 + 캘린더 동기화 | ACT 2 *(F·P)* |
| 시간 맞추기 — When2Meet + AI 추천 + TimeBar 자동 주입 | ACT 3 *(I)* |
| 앱 없는 친구 — 카톡 링크로 게스트 참여 | ACT 1 |
| 빠른 응답 — 단축 경로 (6~15s → 3~5s) | ACT 5 *(E)* |
| AI 학습/활용 — 6 카테고리 학습 → 다음 모임 자동 반영 | ACT 5 (활용) + ACT 6 (학습) |

## 비상 대응 (체크리스트)

| 상황 | 대응 |
| --- | --- |
| Gemini API rate limit | 패턴 fallback으로 자동 전환 (정상 동작 보장) |
| WS 연결 끊김 | AI 패널 상단 끊김 배너 자동 표시, 5초 후 재연결 |
| TimeBar 데이터 추출 실패 | 로그 `TimeBar entity extraction failed`, 일반 흐름 fallback |
| LLM judge가 stalemate 판정 안 함 | 5번째 메시지 추가 입력으로 카운터 누적 |
| Kakao API 키 누락 | 더미 슬롯 표시 |
| K 모달 PATCH 실패 | 모달 에러 메시지, 재시도 |
