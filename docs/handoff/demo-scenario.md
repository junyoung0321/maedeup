# 통합 시연 시나리오 — "오랜만의 동아리 회식, 매듭이 다 해줌"

**컨셉**: 평범한 회식 잡기 한 번에 매듭의 핵심 기능이 모두 자연스럽게 노출.<br>

**예상 시간**: 약 3분 30초<br>

**룸 수**: 1개 (집중도 ↑, 시연 부담 ↓)

## **참여자**

| **멤버** | **역할** | **Personal Data 시드 (사전 ✨)** |
| --- | --- | --- |
| 지민 | 방장 ✅ | 한식·강남·저녁형 ✨ |
| 수현 | 멤버 ✅ | 채식·홍대 비선호 ✨ |
| 민수 | 멤버 ✅ | 지하철 ✨ |
| 예린 | **게스트** (앱 없음, 카톡 링크) | — |

> **사전 시드 (D-1)**: `docker exec maedeup-api python -m scripts.seed_demo_personal_data --room <id>` — ACT 0 메인 ✨ 노출 + ACT 5 reasoning 이름 인용용.

## **흐름 한눈에**

```markdown
ACT 0  메인 투어              30s   [Personal Data ✨ + 위젯 노출]
ACT 1  모임 생성 + 초대 + 게스트 30s   [플로팅바 + InviteModal + 카톡 링크]
ACT 2  채팅 교착 → 다음주 확장 45s   [stalemate + 자연어 거부 + P + N]
ACT 3  TimeBar 시간 합의      25s   [all_members_selected + I]
ACT 4  Partial 카드 발행      10s   [선호 장소 비어있음 → I]
ACT 5  AI 패널 단축 + 확정    30s   [direct_request + Personal Data 활용 + E + J]
ACT 6  학습 + 클로징          30s   [extractor + ✨ 추가 + 메인 누적]
```

## **ACT 0. 메인화면 투어 (30초)**

| **행동** | **시스템/멘트** |
| --- | --- |
| 메인화면 노출 | `ExplorePage` 9개 위젯 |
| `PersonalData` ✨ 가리키며 | *"이 ✨가 매듭이 이전 모임 대화에서 자동 학습한 데이터예요. 한식·강남·저녁형 — 다 채팅에서 추출됐습니다."* |
| `MeetingList` / `MiniCalendar` | *"이전 모임이 누적되고 캘린더에도 표시됩니다."* |
| 플로팅 바 | *"새 모임은 여기서 시작합니다."* |

## **ACT 1. 모임 생성 + 친구 초대 + 게스트 (30초)**

| **누가** | **행동** | **시스템** |
| --- | --- | --- |
| 지민 | 메인 → 플로팅 바 **"모임 생성"** 클릭 | 모임 생성 페이지 |
| 지민 | 모임명 `동아리 종강 회식` / 카테고리 식사 / 친구 체크 (수현·민수) → "모임 생성" | 채팅방 진입 |
| 지민 | 선호도 팝업 → 가능 시간 `평일 저녁`, **선호 장소 비워둠** | "일정 조율 시작" |
| 지민 | 채팅방 상단 **"초대" 버튼** → `InviteModal` → **카톡 게스트 링크 복사** (예린용) | 게스트 링크 발급 |
| 수현·민수 | (모바일) `NotificationPanel` 알림 → 클릭 → 입장 + 선호도 (장소 비워둠) | 멤버 갱신 |
| 예린 | (모바일) 카톡 링크 → 닉네임 `예린` → 게스트 입장 | JWT 발급, 게스트 표시 |

> **시연 멘트**: *"모임 만들고 친구 초대. 수현·민수는 알림으로, 예린이는 앱 없어서 카톡 링크로 게스트 참여."*

## **ACT 2. 채팅 교착 → 자연어 거부 → 다음주 자동 확장 (45초)**

| **누가** | **채팅** | **시스템** |
| --- | --- | --- |
| 지민 | "다들 시험 끝나고 한번 보자!" | (1/4) |
| 수현 | "5월 8일 금요일은 동아리 MT라 안 돼" | (2/4) |
| 민수 | "9일은 본가 내려가야 해서 패스" | (3/4) |
| 예린 | "10일 토요일은 좀 쉬고 싶다… 다음주 어때?" | **교착 감지** |
| 시스템 | — | "대화가 길어지네요, AI가 정리해볼게요 🗓️" *(B)* |
| 시스템 | rejected 5/8·5/9·5/10 → 후보 소진 → **다음주 자동 확장** *(N)* | **추천 카드**: "5/11 (월) 18:00 — 전원 가능"<br>**캘린더**: 5/8·5/9·5/10 빨간 카운트 동기화 *(P)* |

> **시연 멘트**:
>
> 1. *"4번째 메시지에서 자동 개입. 카톡이라면 흐지부지 됐을 거예요."*
> 2. *"'동아리 MT', '본가', '쉬고 싶다' — 거부 발언을 정확히 이해해서 후보에서 제외 + 캘린더에도 빨간 카운트로 동기화."*
> 3. *"이번 주가 다 안 되니까 매듭이 알아서 다음주로 후보를 확장합니다."*

## **ACT 3. TimeBar 시간 합의 (25초)**

| **누가** | **행동** | **시스템** |
| --- | --- | --- |
| 지민 | 5/11 캘린더 클릭 → TimeBar 18:00~21:00 | "지민님 선택 중" 실시간 |
| 수현 | TimeBar 19:00~22:00 | 겹치는 19:00~21:00 진한색 |
| 민수·예린 | TimeBar 18:00~22:00 | **all_members_selected** *(I)* |
| 시스템 | TimeBar 데이터 entity 자동 주입 | AI 패널: "모두 시간 선택 완료! 19:00~21:00이 겹쳐요" *(B)* |

## **ACT 4. Partial 카드 발행 (10초)**

| **누가** | **행동** | **시스템** |
| --- | --- | --- |
| 시스템 | 선호 장소 비어있음 → **Partial 카드** *(I)* | "5/11 19:00 ✅" + "🔍 장소 정해주세요" |

> **시연 멘트**: *"선호 장소를 안 정했어도 일단 시간만 카드로 발행. 장소는 두 가지 방법으로 채울 수 있는데, 오늘은 AI 추천 받아볼게요."*

## **ACT 5. AI 패널 단축 → Personal Data 활용 → 확정 (30초)**

| **누가** | **행동** | **시스템** |
| --- | --- | --- |
| 지민 | (AI 패널) "강남에서 다 같이 갈만한 한식집" | quick_classify → place → **단축 경로** *(E)* |
| 지민 | (채팅에 추가 발화) "나 비린 거 별로야. 회집은 빼자" | personal data 학습 후보 누적 |
| 시스템 | (3~5s) | **장소 카드** + reasoning: *"수현님 채식·홍대 비선호 ✨ 반영. 강남 한식 중 채식 옵션 있는 곳 위주."* |
| 지민 | 장소 클릭 → 캘린더 패널 PlaceDetailPane → "이 장소로 확정" | maedeup_card 갱신 *(J)* — 같은 카드가 partial → 완성으로 진화 |

> **시연 멘트**:
>
> 1. *"의도가 명확하니까 단축 경로 — 평소 6~15초 → 3~5초."*
> 2. **(임팩트 ↑↑)** *"reasoning 보세요 — '수현님 채식'. 수현이 한 마디도 안 했는데, 이전 모임에서 학습된 데이터로 자동 반영됐어요."*
> 3. *"같은 카드가 partial → 완성으로 진화하는 거 보이시죠. 새 카드 쌓이는 게 아니라 모임의 라이프사이클입니다."*

## **ACT 6. 학습 모먼트 + 메인 복귀 (30초)**

| **누가** | **행동** | **시스템** |
| --- | --- | --- |
| 시스템 | 모임 종료 → `personal_data_extractor` 호출 → 채팅 transcript 분석 | 지민 `food_restrictions`에 "비린 음식" 추가, `is_ai_filled=True` |
| 지민 | 메인화면 복귀 | `MeetingList`에 새 모임 누적 / `UpcomingMeeting`에 다가오는 일정 / `MiniCalendar` 점 표시 / **`PersonalData`에 ✨ 비린 음식 새 항목** |

> **시연 마무리 멘트**:
>
> *"방금 지민이가 '비린 거 별로'라고 한 거 — 메인으로 돌아오면 ✨로 새로 추가돼 있어요. 다음 모임 만들면 매운 거든 비린 거든 자동으로 빠집니다.<br>카톡과 다른 점 셋 — **자동 개입**, **자연어 이해**, **AI 학습/활용**. 이게 매듭입니다."*

## **백엔드 보완 우선순위 (5일 마감 기준)**

| **우선** | **작업** | **어느 ACT** |
| --- | --- | --- |
| **🔥 P0** | 해결점 P 정교화 (번복·발신자 ID 매핑·게스트 정책) | ACT 2 |
| **🔥 P0** | TimeBar 합의 + 선호 장소 비어있음 → Partial 카드 발행 분기 안정화 | ACT 4 |
| **🔥 P0** | Personal Data 학습 즉시 반영 (모임 종료 → ✨ 메인 위젯) + `DEMO_FALLBACK_ENABLED` 검증 | ACT 6 |
| **P1** | quick_classify에서 단축 경로 시 personal data reasoning 인용 보장 (`_get_room_member_constraints` 호출 누락 검사) | ACT 5 |
| **P1** | 추천 카드 reasoning 텍스트에 ✨ 데이터 명시 인용 (예: *"수현님 채식 ✨ 반영"*) — 프롬프트 강화 | ACT 5 |
| **P1** | 후보 소진 → 다음주 확장 회귀 테스트 (4명 동시 거부 케이스) | ACT 2 |
| **P1** | Stalemate Judge false-positive 차단 + 자연어 거부 회귀 테스트 | ACT 2 |
| **P2** | `NotificationPanel` 알림 발송/수신 흐름 정상화 | ACT 1 |
| **P2** | 카드 갱신 (meeting_id 동일성) — partial → place → maedeup 누적 없이 갱신 회귀 | ACT 4·5 |
| **P2** | 게스트 unavailability 매핑 정교화 | ACT 2 |
| **P2** | Personal Data 시드 스크립트 (D-1 사전 작성용) | 사전 |

P0 3개 / P1 4개 / P2 4개 = 총 11개. 시나리오 안정화 담당 팀원이 P0부터 처리하면 시연 안전선 확보.

## **매듭이 해결하는 5가지 — 어디서 보여주나**

| **문제** | **시연 위치** |
| --- | --- |
| 의견 안 모일 때 자동 개입 + 자연어 거부 + 캘린더 동기화 | ACT 2 *(F·P)* |
| 시간 맞추기 — When2Meet + AI 추천 + TimeBar 자동 주입 | ACT 3 *(I)* |
| 앱 없는 친구 — 카톡 링크로 게스트 참여 | ACT 1 |
| 빠른 응답 — 단축 경로 (6~15s → 3~5s) | ACT 5 *(E)* |
| AI 학습/활용 — 6 카테고리 학습 → 다음 모임 자동 반영 | ACT 5 (활용) + ACT 6 (학습) |
